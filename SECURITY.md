# Правила безопасности

Репозиторий **приватный**, но в нём всё равно не хранятся секреты и сырые
захваты трафика. Перед публикацией из проекта были исключены:

| Что | Почему |
| --- | --- |
| `mts_service_client2027.pfx` | Клиентский сертификат с приватным ключом |
| `logs_to_authn` (16 МБ) | Экспорт Burp с реальными запросами, токенами и OTP |
| `slepok_myak.txt` | Сводка по авторизационным запросам |
| `qrator_login.html`, `qrator_*`, `verify_page.*`, `ui.xml` | Дампы страниц/UI с потенциальными сессиями и номерами |
| `frida-server` (116 МБ) | Бинарник больше лимита GitHub (100 МБ на файл) |
| `soft/session.json`, `soft/last_cards.json`, `soft/logs/*` | Живые сессии и результаты выпуска карт |
| `*.log` | Служебные логи |

## Как восстановить локально

- `frida-server` скачивается с официальных релизов Frida:
  https://github.com/frida/frida/releases (нужна версия под архитектуру
  эмулятора, обычно `frida-server-<version>-android-x86_64`).
- `.pfx`, сессии и логи снимаются заново с вашего стенда и кладутся рядом,
  они уже перечислены в `.gitignore`.

## Если секрет всё же попал в коммит

1. Немедленно отзовите/перевыпустите ключ или токен.
2. Удалите файл из истории (`git filter-repo` / BFG), недостаточно
   просто удалить его следующим коммитом.
